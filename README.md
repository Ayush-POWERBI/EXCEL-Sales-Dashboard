# 📊 Sales Dashboard – Excel VBA

## 📌 Project Overview

This project is an interactive Sales Dashboard developed in Microsoft Excel to analyze sales performance and present key business insights in a clear and user-friendly format.

The project combines Excel data analysis, dashboard development, data visualization, and VBA automation to create an interactive reporting solution.

The objective of this project is to transform raw sales data into meaningful insights that can help understand sales performance, customer trends, product performance, and overall business results.
